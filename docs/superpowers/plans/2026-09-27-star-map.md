# Карта созвездий — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Русскоязычный панорамный 3D-планетарий: статический сайт на Three.js с ~5000 звёзд, фигурами 88 созвездий, мифами и расчётом неба под место/время.

**Architecture:** Статика без сборщика: ES-модули, vendored Three.js, данные в JSON. Камера = наблюдатель в центре небесной сферы; смена времени/места — одна матрица поворота (GMST + широта). Мифы — авторские SVG-силуэты + легенды в JSON.

**Tech Stack:** HTML/CSS/JS (ESM), Three.js (vendored r160+), Python 3 (одноразовый конвертер данных), Node `--test` (юнит-тесты чистой астрономической математики).

**Spec:** `docs/superpowers/specs/2026-09-27-star-map-design.md`

## Рабочий процесс (особенность этого проекта)

Контекст сессий ограничен, поэтому:

1. Каждый **раздел** (Task) выполняется целиком, включая проверку.
2. После успешного выполнения раздела — `git add`, `git commit`, `git push`.
3. **Остановиться** и сообщить пользователю: раздел N готов, можно начинать новую сессию для раздела N+1. Не переходить к следующему разделу в той же сессии, если пользователь явно не попросит.
4. В начале каждой новой сессии: прочитать спеку + этот план + `git log --oneline -5`, продолжить с первого незакрытого (unchecked) раздела.
