# Карта созвездий — спецификация дизайна

Дата: 2026-09-27
Статус: утверждена в диалоге (brainstorming)

## 1. Концепция

Русскоязычный панорамный 3D-планетарий «Карта созвездий» — статический
одностраничный сайт. Пользователь «стоит под ночным небом» и вращает
голову мышью или пальцем. Небо соответствует реальному положению звёзд
для выбранного места и момента времени. При выборе созвездия показывается
мифологическая иллюстрация и легенда.

**Аудитория:** широкая русскоязычная (взрослые + дети), основной трафик —
смартфоны. Принцип UX: «открыл и полетай» — никаких обязательных настроек.

**Критерий успеха:** сайт открывается на телефоне за секунды, показывает
узнаваемое небо «здесь и сейчас», тап по Ориону даёт его подсветку,
силуэт и легенду.

## 2. Функциональность

### 2.1 Небо
- ~5000 видимых невооружённым глазом звёзд (каталог Yale Bright Star,
  порог mag ≤ ~5.8 + все звёзды, входящие в линии созвездий).
- Размер звезды = функция магнитуды; цвет = из индекса B−V.
- Линии фигур и русские названия всех 88 созвездий; подписи у центроидов.
- Млечный Путь — фоновая equirectangular-текстура (NASA/ESO, public
  domain), тусклая подложка.
- Лёгкое мерцание звёзд (шейдер), отключается на слабых устройствах и при
  `prefers-reduced-motion`.
- Линия горизонта с подписями С/Ю/В/З; мягкий ночной градиент «земли».

### 2.2 Время и место
- По умолчанию: геолокация браузера → небо «здесь и сейчас». Отказ —
  fallback Москва + чип «Изменить место?». Модальных препятствий нет.
- Реального тика времени НЕТ — звёзды стоят. Время меняется только через
  панель «Где я?».
- Панель «Где я?» (иконка вверху справа):
  - Место: чип «Моё местоположение» или живой поиск по ~60 городам
    (РФ/СНГ/мир) с координатами.
  - Время: ползунок часов, кнопки ±1 час / ±1 сутки, `input[type=date]`.
    Пересчёт неба на лету (throttle ~60 мс).
  - Подпись: «Вы смотрите небо: {место}, {дата} {время}» — видна, когда
    состояние ≠ сейчас; кнопка «Сегодня» для возврата.
- Состояние в URL: `?c=<город>&t=<ISO>` — шеринable-ссылки.

### 2.3 Взаимодействие с небом
- Drag/свайп — pan по азимуту (360°) и высоте (alt ∈ [−2°, +92°]).
- Инерция после отпускания (off при prefers-reduced-motion).
- Щипок / колесо мыши — FOV zoom в диапазоне 60°↔25°.
- Двойной тап — сброс: север, середина неба.
- Стартовая подсказка-жест, исчезает после первого взаимодействия.

### 2.4 Выбор созвездия
- Тап по фигуре или подписи: линии становятся янтарными, фон гасится,
  поверх звёзд проступает SVG-силуэт (draw-in ~1 с).
- Bottom sheet (на десктопе — боковая панель): название рус/лат,
  мини-иллюстрация, легенда (или краткое описание), «Лучшее время:
  {месяц}», ярчайшая звезда. Закрытие: тап мимо / крестик / свайп вниз.
- Лента «Все созвездия»: горизонтальный список 88 названий, сортировка по
  видимости сейчас (невидимые приглушены). Тап — плавный доворот камеры
  (slerp ~1.2 с) + карточка.

### 2.5 Контент: мифы
- Стартовый набор 12–15 созвездий с иллюстрациями и легендами: Орион,
  Большая и Малая медведицы, Лебедь, Кассиопея, Персей, Андромеда, Цефей,
  Дракон, Телец, Близнецы, Дева, Скорпион, Лира, Пегас.
- Легенды — оригинальные пересказы на русском, 3–6 предложений, единый
  сказочно-мифологический тон. Позиционный текст в `myths.json`.
- Иллюстрации — стилизованные контурные SVG-силуэты (золотистые
  полупрозрачные линии), привязаны к центроиду и масштабу фигуры.
- Остальные созвездия: карточка с линиями + факт-описание (2–3
  предложения: что видно, когда искать, ярчайшая звезда).
- Пайплайн расширяем: добавить созвездие = запись в myths.json + SVG.

## 3. Архитектура

Статика без сборщика: ES-модули, Three.js vendored-файлом (без CDN).
Разработка — любой локальный статический сервер. Деплой — GitHub Pages.

```
├── index.html
├── css/style.css
├── js/
│   ├── main.js          — точка входа, цикл, авто-degrade, WebGL-fallback
│   ├── scene.js         — сцена Three.js: звёзды, линии, Млечный Путь, горизонт
│   ├── astromath.js     — JD, GMST, RA/Dec→Alt/Az, прецессия (линейная)
│   ├── skydata.js       — загрузка/парсинг данных, B−V→RGB
│   ├── controls.js      — pan/инерция/щипок/double-tap
│   ├── location.js      — геолокация, города, время, URL-состояние
│   └── ui.js            — карточка созвездия, лента, панель «Где я?»
├── data/
│   ├── stars.json           — звёзды: id, ra, dec, mag, bv, name?
│   ├── constellations.json  — 88 шт.: id, ru/la названия, lines (пары id), центроид, лучший месяц, описание
│   ├── myths.json           — легенды + путь SVG для 12–15 созвездий
│   └── milkyway.jpg         — ~4096×2048, 1–2 MB
├── assets/myths/*.svg     — силуэты
├── vendor/three.module.js
└── tools/prepare_data.py  — одноразовый конвертер каталогов → data/*.json (результат в git)
```

Ключевые решения:
- Камера = наблюдатель в центре сферы фиксированного радиуса; поворот
  камеры = Alt/Az. Позиции звёзд в экваториальных координатах статичны:
  смена времени/места = одна матрица поворота (GMST + широта), без
  перестройки буферов.
- Звёзды — один `THREE.Points` (~5000 вершин); линии — `LineSegments`.
- Прецессия — линейная аппроксимация ±несколько веков от J2000
  (визуальной точности достаточно). Собственные движения звёзд
  игнорируются.

### 3.1 Источники данных
- Звёзды: Yale Bright Star Catalogue (Y4), открытый; фильтрация и
  конвертация в `prepare_data.py`.
- Астеризмы (линии фигур): open-source набор линий западных созвездий
  (формат проекта asterisms/Western line data, id-ссылки на BSC);
  валидация: все концы линий присутствуют в stars.json.
- Млечный Путь: NASA/ESO panoramic composite, public domain.
- Тексты легенд и иллюстрации: создаются специально для проекта (авторские).

## 4. Обработка ошибок и деградация

- Нет WebGL → дружелюбная статичная заглушка с описанием проекта.
- Отказ/недоступность геолокации → Москва, сайт полностью работает.
- Низкий devicePixelRatio/слабое устройство → меньше свечений, без
  мерцания; rAF на паузе, когда вкладка скрыта.
- Повреждённый/незагруженный JSON города/данные → не крэш: дефолты +
  console.warn.
- `prefers-reduced-motion` → без инерции и draw-in-анимаций.

## 5. Вне scope (этап 2)

Планеты и Луна, объекты глубокого космоса, полный набор 88 мифов,
PWA/офлайн-кэш, англоязычная версия, аккаунты/сохранение наблюдений.

## 6. Глобальные ограничения

- Никаких npm-зависимостей в рантайме; только статические файлы.
- Three.js — vendored `three.module.js` (проверенная версия r160+).
- Все тексты интерфейса и контента — на русском.
- Мобильный первый: управление и вёрстка проверяются на 390×844.
- Итоговый JS < ~700 KB gzip (с Three.js); данные грузятся асинхронно
  с экраном загрузки.
